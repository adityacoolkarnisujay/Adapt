# Adapt

Ideas - 

Aditya - 
1. Traffic patterns in IoT devices can allow threats to analyze and access personal daily patterns, solution is to create fake traffic patterns to make real user activity harder to distinguish. Basically a personalised routine based on pre existing user patterns. !!!!!!!!!!!!!!!!

2. Problem: A compromised sensor or poorly configured routine can trigger a sensitive action through otherwise legitimate automations.

Proposed solution: A local policy engine checks commands using their origin, triggering event, and current household state. Ordinary commands execute immediately; sensitive commands require additional authorization when their context is insufficient.

3. Creating a pre approved communication map between different IoT devices. !!!!!!!!!!!!!!!!!!

4. Develop a local smart home gateway that checks the origin and context of automation commands, blocks unauthorized sensitive actions, and limits selected sensor information shared with external services.
